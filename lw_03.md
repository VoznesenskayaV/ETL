## Архитектура решения  

Реализована трехслойная архитектура:

- **Source Layer**  
  - PostgreSQL — данные о клиентах  
  - Excel — справочник товаров  
  - CSV — транзакции продаж  

- **Storage Layer**  
  - Staging-таблицы в MySQL  
  - Итоговая таблица `fact_sales_lw3`  

- **Business Layer**  
  - SQL-представление `view_sales_report_lw3`  
  - Визуализация данных

### 4. Загрузка данных в MySQL  

Данные загружены в БД и создано представление:

`CREATE OR REPLACE VIEW view_sales_report_lw3 AS
SELECT
    CONCAT(first_name, ' ', last_name) AS customer_name,
    category,
    SUM(sale_amount) AS total_sales,
    COUNT(*) AS transactions_count,
    SUM(quantity) AS total_quantity
FROM fact_sales_lw3
GROUP BY CONCAT(first_name, ' ', last_name), category;`
